# 챠위키 v2.8.1

## 설치

1. RisuAI 설정 → 플러그인 → ＋ 를 누르고 `char_wiki.js` 를 고릅니다. 파일은 [Releases](https://github.com/daelar99-rgb/char_wiki/releases/latest) 에서 받습니다.
2. 권한 확인 창이 뜨면 허용합니다 (API 3.0 플러그인).
3. 채팅 입력 칸 오른쪽의 ≡ 메뉴와 입력 칸 왼쪽에 📖 챠위키 버튼이 생깁니다. 입력 칸 왼쪽 버튼은 설정 › 보기에서 끌 수 있습니다.

## 업데이트

깃허브에 새 버전이 올라오면 챠위키를 열 때 머리줄에 주황 점이 달린 **업데이트** 탭이 생깁니다. 탭을 누르면 리수에서 어디를 누르면 되는지 그림으로 보여 줍니다.

1. 리수 왼쪽 위 ≡ → 톱니바퀴(설정) → 플러그인 을 엽니다.
2. 📖 챠위키 줄 오른쪽의 초록색 ＋ 를 누르고, 확인 창에서 YES 를 누릅니다.
3. 권한 확인 창이 다시 뜨면 허용합니다. 만들어 둔 위키와 챠위키 설정은 그대로 남지만, 플러그인 설정의 `source_limit` 은 비워지므로 바꿔 썼다면 다시 넣어 주세요.

업데이트 탭의 다음에 를 누르면 그 버전에는 탭을 다시 띄우지 않습니다. 초록색 ＋ 는 v2.8.0 이상을 설치한 뒤부터 뜹니다. v2.7.0 이하를 쓰고 있다면 [Releases](https://github.com/daelar99-rgb/char_wiki/releases/latest) 에서 `char_wiki.js` 를 받아 한 번 직접 설치해 주세요.
