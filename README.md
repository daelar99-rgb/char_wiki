# 챠위키 v2.6.0

지금 채팅 중인 봇의 봇 설명과 로어북(원하면 글로벌 노트까지)을 읽고, 메인 모델이나 보조 모델이 나무위키식 인물 문서를 써 주는 RisuAI 플러그인입니다.
화면은 인물 목록, 문서, 정보 상자, 목차, 각주로 이루어지며, 색과 버튼은 나무위키를 따릅니다.

## 설치

1. RisuAI 설정 → 플러그인 → ＋ 를 누르고 `챠위키_v2.6.0.js` 를 고릅니다.
2. 권한 확인 창이 뜨면 허용합니다 (API 3.0 플러그인).
3. 채팅 입력 칸 오른쪽의 ≡ 메뉴와 입력 칸 왼쪽에 📖 챠위키 버튼이 생깁니다. 입력 칸 왼쪽 버튼은 설정 › 보기에서 끌 수 있습니다.

## 쓰는 법

1. 위키를 만들 봇과 채팅을 연 뒤 📖 챠위키 를 엽니다.
2. 설정 탭의 분석할 곳 에서 모델에게 보낼 원문을 고릅니다. 기본값은 봇 설명과 캐릭터 로어북입니다. 인물 목록을 글로벌 노트에 둔 봇이라면 글로벌 노트를 켜 주세요.
3. 📖 위키 만들기 를 누릅니다. 플러그인은 다음 순서로 모델을 부릅니다.
   - 인물 목록과 세계관 요약 뽑기 (1회)
   - 인물마다 대표 사진 고르기 (1회)
   - 세계관 문서 쓰기 (1회)
   - 인물 문서 쓰기 (설정한 인원씩 묶어 묶음마다 1회, 기본 1명씩)
4. 쓰는 도중에 위키 창을 닫아도 리수가 켜져 있으면 백그라운드에서 끝까지 쓰고 저장합니다. ■ 중단 을 눌러도 이미 쓴 문서는 남고, ▶ 이어 쓰기 로 남은 인물만 이어서 쓸 수 있습니다.
5. 문서가 마음에 들지 않으면 문서 위쪽의 이 문서 다시 쓰기 를 두 번 눌러 그 사람만 다시 씁니다. 세계관 문서도 같은 방식으로 다시 쓸 수 있습니다.
6. 처음부터 다시 만들려면 설정 탭 → 챠위키 → ↻ 다시 만들기 를 5초 안에 두 번 누릅니다.

만든 위키는 봇마다 따로 저장되고, 다음에 열면 저장본이 바로 나옵니다.

### 유저 문서

인물 칸 맨 앞의 유저 칸에는 지금 쓰는 페르소나의 문서가 들어갑니다. 채팅에 유저 입력이 3번 이상 쌓이면 위키를 만들 때 함께 쓰고, 그 전에는 유저 칸의 이 문서 쓰기 버튼이 꺼져 있습니다. 근거로는 페르소나 설명과 이 채팅의 최근 메시지(기본 100개)만 보냅니다.

## 설정

설정 탭에서 고른 값은 저장되며, 모든 봇에 똑같이 적용됩니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 분석 모델 | 보조 모델 | 메인 모델과 보조 모델 중 하나를 고릅니다. 권장 모델은 gemini-flash입니다. |
| 한 번에 분석할 인물 수 | 1명 | 1 · 3 · 5 · 10명 중에 고릅니다. 많을수록 호출은 줄지만 응답이 끊기기 쉽습니다. |
| 문서 언어 | 한국어 | 한국어 또는 English. 바꾸면 다음에 쓰는 문서부터 적용됩니다. |
| 분석할 채팅 수 | 100개 | 유저 문서를 쓸 때 보내는 최근 메시지 수입니다. |
| 추가 지시 | 비어 있음 | 적은 글을 모든 요청의 원문 위에 붙여 보냅니다. 예: `성격 문단은 길게 써라.` |
| 스포일러 모두 보기 | 꺼짐 | 가린 내용을 한꺼번에 펼칩니다. |
| 글자 크기 | 보통 | 작게 · 보통 · 크게 · 아주 크게 |

플러그인 설정의 `source_limit`(기본 40000)은 한 번에 모델에 보내는 원문의 최대 글자 수입니다. 로어북이 길어 뒤쪽 항목이 잘리면 설정 탭에 표시되므로, 모델의 컨텍스트가 넉넉하면 값을 늘리세요.

## 스포일러

원문이 숨긴 정체, 반전, 비밀은 가려서 보여 줍니다. 회색 막대나 「스포일러」 띠를 누르면 내용이 보입니다.

## 인물 그림

봇에 등록된 에셋 이름 전체를 모델에게 보내, 인물마다 대표 그림 한 장을 고르게 합니다. 목록에 없는 이름이 오거나 맞는 그림이 없으면 회색 실루엣이 나옵니다. 사진이 틀리면 문서 위쪽의 이미지 다시 찾기 를 누릅니다.

## 알아 둘 점

- 고른 모델의 최대 응답 토큰 값을 그대로 씁니다. 응답이 자주 끊기면 이 값을 늘리거나 한 번에 분석할 인물 수를 줄이세요.
- 요청이 실패하거나 응답이 올바른 JSON이 아니면 3번까지 저절로 다시 시도합니다.
- 모델은 원문에 있는 내용만 쓰도록 지시받지만, 모델에 따라 틀린 내용이 섞일 수 있습니다.
- 온도와 Top K 같은 파라미터는 리수 설정을 따릅니다. Gemini(Vertex AI)에서 `topK value of 0` 오류가 나면 Top K 를 1 이상으로 바꾸세요.
- 프로바이더 플러그인(예: provider-manager)이 넣어 준 모델도 그대로 부를 수 있습니다.
- 문서 맨 아래의 이 문서 복사 를 누르면 보이는 모양 그대로 복사해 구글 문서, 워드, 게시판 등에 붙여 넣을 수 있습니다.
