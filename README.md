# 챠위키 v2.11.0

봇 설명과 로어북을 읽고, 모델이 나무위키처럼 인물 문서를 써 주는 RisuAI 플러그인입니다.
인물 목록·정보 상자·목차·각주로 이루어진 위키를 봇마다 따로 저장합니다.

## 에셋 탭 (v2.10.0 추가)

패널 머리줄의 **에셋** 탭을 누르면 지금 봇에 들어 있는 그림·소리·영상(추가 에셋, 감정 그림, 봇 대표 그림)만 모아서 보여 줍니다.

- 위키를 만들어 둔 봇은 위키 인물별로 에셋을 묶습니다. 위키가 없는 봇은 에셋 이름의 앞부분(예: `alice_happy` 의 `alice`)으로 묶습니다.
- 처음 열면 첫 인물의 에셋만 보여 줍니다. 위쪽 칩을 눌러 다른 인물로 바꾸고, **전체** 칩을 누르면 모든 묶음을 한꺼번에 봅니다. 고른 칩을 한 번 더 눌러도 전체로 돌아갑니다.
- 검색 칸은 고른 칩 안에서 이름을 찾습니다. 칩마다 찾은 개수가 나오고, 하나도 없는 칩은 흐리게 표시됩니다. 고른 묶음에 없으면 「전체에서 찾기」 버튼이 나옵니다.
- 칸을 누르면 그림을 크게 보여 주고, 소리와 영상은 그 자리에서 재생합니다.
- 보기 전용입니다. 에셋을 고치거나 지우지 않고, 모델도 부르지 않으므로 비용이 들지 않습니다.

## 설치

1. RisuAI 설정 → 플러그인 → ＋ 를 누르고 `char_wiki.js` 를 고릅니다. 파일은 [Releases](https://github.com/daelar99-rgb/char_wiki/releases/latest) 에서 받습니다.
2. 권한 확인 창이 뜨면 허용합니다 (API 3.0 플러그인).
3. 리수 왼쪽 사이드바의 ☰ 를 펼치면 🌀 아래에 책 그림과 「챠위키」 글자가 있는 버튼이 생깁니다. 채팅 입력 칸 왼쪽에도 같은 버튼이 생기고, 입력 칸 오른쪽의 ≡ 메뉴에는 📖 챠위키 버튼이 생깁니다. 모바일 화면에는 사이드바가 없으니 ≡ 메뉴의 버튼을 씁니다. 입력 칸 왼쪽 버튼은 설정 › 보기에서 끌 수 있습니다.
